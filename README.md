# Ejemplo OpenAI SDK con tools

## Setup

- 1 Comprobar versión de node. Debe ser 24 o superior

```bash
node -v
```

- 2 Instalar dependencias

```bash
npm install
```

- 3 Crear archivo .env con el contenido de .env.example

```bash
cp .env.example .env
```

- 3 Crear archivo .env con el contenido de .env.example

```bash
cp .env.example .env
```

## Correr el script

```bash
npm start
```
