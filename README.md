# Ejemplo OpenAI SDK con tools

## Setup por primera vez

### 1 Comprobar versión de node. Debe ser 24 o superior

```bash
node -v
```

### 2 Instalar dependencias

```bash
npm install
```

### 3 Crear archivo .env con el contenido de .env.example

```bash
cp .env.example .env
```

### 4 Editar .env para que tenga la api key real

------

## Correr el script cada vez

```bash
npm start
```
